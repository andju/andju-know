# Recommended Software

## Media

### [IrfanView](https://www.irfanview.com/)
**Price:** free | **Platform:** Windows | **Open Source:** No

Powerful image viewer with a wide range of supported formats and basic editing capabilities.

### [VLC Media Player](https://www.videolan.org/)
**Price:** free | **Platform:** Multiple | **Open Source:** [Yes](https://github.com/videolan/vlc)

Media player with a wide range of supported formats.

## Productivity

### [Obsidian](https://obsidian.md/)
**Price:** free | **Platform:** Multiple | **Open Source:** No

Knowledge management and note software, similar to Microsoft OneNote or Evernote. It is based on the open Markdown format and easily extensible by plugins.
